# 동명측량설계사무소 홈페이지

측량과 토지 인허가(개발행위, 농지·산지전용, 공장, 태양광 등) 업무와 인허가 실적을 소개하는 홈페이지입니다.

## 내용 고치기 (관리자 페이지)

1. `관리자_실행.bat`을 더블클릭합니다. (파이썬 3 필요)
2. 브라우저에 관리자 화면이 열립니다: http://127.0.0.1:8080/admin/
3. 고친 뒤 **저장**(또는 Ctrl+S)을 누르면 `index.html`이 새로 만들어집니다.
4. 사이트 확인: http://127.0.0.1:8080/
5. 끝나면 검은 창을 닫습니다.

관리자 화면에서 고칠 수 있는 것

- 인허가 실적 추가·수정·삭제
- 첫 화면 문구, 업무 안내
- 진행 절차, 상담 준비물
- 사무소 정보(대표, 주소, 전화 등), 검색용 제목·설명

관리자 화면은 내 컴퓨터(127.0.0.1)에서만 열립니다. 저장할 때마다 이전 내용이 `data/backup/`에 남습니다(저장소에는 올리지 않음).

## 폴더 구조

| 경로 | 설명 |
| --- | --- |
| `index.html` | 사이트 첫 페이지 (**자동 생성**, 직접 고치지 않음) |
| `js/projects.js` | 실적 데이터 (**자동 생성**) |
| `data/site.json` | 문구·연락처 원본 |
| `data/projects.json` | 실적 원본 |
| `templates/index.template.html` | 페이지 틀 (디자인을 바꿀 때 고침) |
| `css/style.css`, `js/main.js` | 디자인, 실적 필터·슬라이드 동작 |
| `img/` | 東明 로고, 파비콘 |
| `admin/` | 관리자 화면 |
| `build.py` | 데이터 + 틀 → `index.html` 생성 |
| `server.py` | 사이트·관리자용 로컬 서버 |

명령어로 직접 실행할 때

```
python server.py      # 서버 켜기 (저장 시 자동으로 build)
python build.py       # index.html만 다시 만들기
```

## 인터넷에 올릴 때

`index.html`, `css/`, `js/`, `img/` 만 있으면 정적 웹호스팅(GitHub Pages 등)에서 그대로 열립니다.
관리자 화면과 `server.py`는 내 컴퓨터에서 내용을 고칠 때만 씁니다. 고친 뒤 바뀐 파일을 다시 올리면 사이트에 반영됩니다.
